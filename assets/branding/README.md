# vcli branding

- [Animated Reborn logo](logo-reborn.gif): original approved CRT animation, 640×640, 168 frames, 9 seconds. Used in the repository README; GitHub displays GIF animations inline.
- [Static CRT logo](logo-crt.webp): 640×640 static artwork for documentation and full-resolution previews.
- [Small CRT logo](logo-crt-256.webp): original 256×256 WebP (~2.9 KB) from the staged branding branch, retained for lightweight embeds.
- [Monochrome logo](logo-mono.svg): scalable vector artwork.
- [Favicon](favicon.svg): phosphor-green prompt and block cursor for a future website.

Palette: `#69F52B` (phosphor), `#031609` (CRT black). These are documentation assets, not CLI runtime dependencies.

Website integration: reference the favicon in the HTML head when GitHub Pages is configured. GitHub's repository icon cannot be changed via a favicon file.
